📚 Data Structures and Algorithms in C

A comprehensive collection of C programs implementing core data structure operations, classic algorithms, and memory management techniques. Ideal for students, educators, and interview preparation.

| `CSCAN.c`                    | CSCAN disk scheduling                 |
| `CircularQueue.c`            | Circular Queue implementation         |
| `Deletion.c`                 | Array element deletion                |
| `Disk-Fcfs.c`                | Disk Scheduling using FCFS            |

🧠 Topics Covered

    🔁 Sorting Algorithms: Bubble, Selection, Insertion, Merge, Quick

    🔍 Searching: Linear and Binary Search

    📦 Memory Management: Best Fit, First Fit, Worst Fit

    💾 Disk Scheduling: FCFS, SCAN, CSCAN

    🧮 Polynomial and Matrix operations

    🔗 Linked Lists: Singly, Stack/Queue using Linked List

    📊 Queue Variants: Circular, Double-ended, Priority

    🧠 Stack: Array and Linked List based

    ✍️ Expression Parsing: Prefix, Postfix

⚙️ How to Run

# Compile any file with GCC
gcc filename.c -o output
./output

    Basic knowledge of C programming
